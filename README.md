# 📈 GitHub Daily Hot - 每日热门项目追踪

> 自动追踪 GitHub 每日热门项目和星标趋势

---

## 📁 目录结构

```
github-daily-hot/
├── README.md              # 本文件
├── daily/                 # 每日数据
│   └── 2026/
│       └── 03/
│           └── 2026-03-13/
│               ├── trending.md      # 热门项目列表
│               └── summary.md       # 每日总结
└── archives/              # 历史归档
```

---

## 🎯 功能说明

- **每日自动更新** - 抓取 GitHub Trending 热门项目
- **星标追踪** - 记录项目星标增长趋势
- **分类整理** - 按语言/领域分类展示
- **历史归档** - 完整的历史数据可追溯

---

## 📊 数据字段

每个项目记录包含：
- 项目名称 & 链接
- 所属语言
- 今日星标数
- 星标增长率
- 简短描述
- 热门标签

---

## 🤖 自动化

系统每天自动：
1. 抓取 GitHub Trending 数据
2. 创建当日文件夹
3. 生成 trending.md 和 summary.md
4. 提交并推送更新

---

## 📝 使用说明

查看今日热门：
```bash
cat daily/2026/03/2026-03-13/trending.md
```

查看历史数据：
```bash
ls daily/2026/
```
